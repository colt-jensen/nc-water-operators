# NC Water Operator Recruitment Program — Utility Opt-In Page

Public "learn more and opt in" page aimed at **North Carolina water utility
organizations** considering joining the NCRWA / UNC School of Government
operator recruitment study as participating sites.

Built with [Quarto](https://quarto.org).

## Local preview
```bash
quarto preview
```

## Deploy (GitHub Pages)
```bash
quarto publish gh-pages
```
Rendered output goes to `/_site` (git-ignored); deployment pushes it to the `gh-pages` branch.
Live at: https://colt-jensen.github.io/nc-water-operators/

## Source files
- `_quarto.yml` — site config, section navbar, footer
- `custom.scss` — brand theme (navy/steel) and call-to-action button
- `index.qmd` — utility-facing opt-in page
